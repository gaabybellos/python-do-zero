## Reportando uma Vulnerabilidade ou Problema de Integridade

Este repositório é educacional e não processa credenciais ou dados reais de produção. Ainda assim, caso identifique:
- Alguma dependência de desenvolvimento vulnerável;
- Algum script ou workflow de CI com permissão excessiva;
- Qualquer conteúdo que viole direitos autorais ou integridade acadêmica;

Por favor, abra uma **Issue** detalhando o ponto encontrado ou entre em contato diretamente pelo perfil do GitHub (`@gaabybellos`).
