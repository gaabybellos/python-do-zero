# Exemplos Executáveis do Módulo 01 (`exemplos/`)

Estes 3 exemplos demonstram na prática os conceitos ensinados em [`../conteudo-teorico.md`](../conteudo-teorico.md) usando **problemas análogos** (diferentes dos exercícios do módulo, para preservar seu raciocínio).

---

## Como Executar os Exemplos no Terminal

Na raiz do repositório (`python-do-zero`), execute:

```powershell
# Exemplo 01: Variáveis, constantes e tipos básicos (sem input)
python modulos/01-introducao-e-variaveis/exemplos/exemplo_01_variaveis_e_tipos.py

# Exemplo 02: Entrada de dados com input(), conversão int/float e cálculo de área
python modulos/01-introducao-e-variaveis/exemplos/exemplo_02_entrada_e_conversao.py

# Exemplo 03: Cálculo de porcentagem (desconto em livraria) e limpeza de vírgula (QA)
python modulos/01-introducao-e-variaveis/exemplos/exemplo_03_desconto_produto_qa.py
```
