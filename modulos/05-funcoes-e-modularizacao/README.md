# Módulo 05 — Funções, Modularização e Testes com `pytest` (`PYZ-FUN`)

## Objetivos de Aprendizado

1. Criar funções com `def`, parâmetros claros e retorno (`return`).
2. Aplicar o Princípio da Responsabilidade Única (separar `input`/`print` da lógica pura).
3. Documentar funções com *Docstrings* e *Type Hints* básicos.
4. Tratar exceções previsíveis com `try/except` e validar funções com testes automatizados (`pytest`).

---
